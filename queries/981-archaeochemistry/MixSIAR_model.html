MixSIAR model

Creating the model

In this type of model, we treat each pot as a weighted sum of different food sources, each of which has a different mean. The weights for each pot are drawn from a Dirichlet distribution, which can differ by region (bin). I ran the model using the reference data you sent me.

# Load the mixture data
mix <- load_mix_data(
  filename = paste0(DATA_DIR, 'balk.csv'),
  iso_names = c("d13C16", "d13C18"),
  factors = "bin",
  fac_random = TRUE, # including a random effect for region
  fac_nested = FALSE, # we don't have a nested structure in this case
  cont_effects = NULL # column headings of continuous effects -- N/A in this case
)

# Load the source data
# Reference data shared by Isabel
source <- load_source_data(
  filename = paste0(DATA_DIR, 'reference_fats1.csv'),
  source_factors = NULL,
  conc_dep = FALSE, # do not have concentration dependence
  data_type = "raw",
  mix = mix
)

# Load the discrimination data
# we aren't looking at tissue of a consumer, so we just set TDF to 0
# Made a discrimination file following this format:
# https://github.com/brianstock/MixSIAR/blob/master/inst/extdata/wolves_discrimination.csv
discr <- load_discr_data(
  filename = paste0(DATA_DIR, 'discrimination1.csv'),
  mix = mix
)

We are looking for the pots to fall within the convex hull of the sources. It seems like most of the pots do fall within the convex hull, which is a good sign for model fit.

We set an uninformative prior for the model, assuming that all fat sources are equally likely.

# Write the JAGS model file

Interpreting the model

Based on the model results, we want to use the posterior distributions to investigate trends in the contributions of different food sources across the different regions (bins). We can also look at the model diagnostics to check for convergence and model fit.

post_array <- jags.test$BUGSoutput$sims.list$p.fac1
bin_names    <- unique(balk$bin)
source_names <- source$source_names

n_iter <- dim(post_array)[1]

# Build tidy dataframe
posterior_df <- expand.grid(
  iter = 1:n_iter,
  bin = bin_names,
  source = source_names
)

posterior_df$prop <- as.vector(post_array)

summary_df <- posterior_df %>%
  group_by(bin, source) %>%
  summarise(
    median = median(prop),
    lower  = quantile(prop, 0.025),
    upper  = quantile(prop, 0.975),
    .groups = "drop"
  )

# Plot the credible intervals for each source contribution by bin
ggplot(summary_df, aes(x = bin, y = median)) +
  geom_point() +
  geom_errorbar(aes(ymin = lower, ymax = upper), width = 0.2) +
  facet_wrap(~ source, scales = "free_y") +
  theme_minimal() +
  labs(
    title = "Posterior source contributions by region",
    x = "Region (south → north)",
    y = "Estimated proportion (median ± 95% CI)"
  )

We have a lot of overlap in credible intervals. We are trying to estimate four sources (marine, ruminant fat, nonruminant fat, dairy) using only 2 isotopes, so it is not surprising that we have a lot of uncertainty in the estimates. We do see some trends, however, such as increase in dairy from south to north, and a strong marine contribution in region a.

I will demonstrate how we could compare the contribution of dairy between two regions:

# Extract posterior samples for dairy contribution in regions a and g1
dairy_a <- post_array[, which(bin_names == "a"), which(source_names == "dairy")]
dairy_g1 <- post_array[, which(bin_names == "g1"), which(source_names == "dairy")]
# Calculate the difference in dairy contribution between regions a and g1
dairy_diff <- dairy_g1 - dairy_a
# Summarise the difference
dairy_diff_summary <- data.frame(
  median = median(dairy_diff),
  lower = quantile(dairy_diff, 0.025),
  upper = quantile(dairy_diff, 0.975)
)
dairy_diff_summary
##         median     lower     upper
## 2.5% 0.3394477 0.1812038 0.5163814
# Visualise the difference:
ggplot(data.frame(diff = dairy_diff), aes(x = diff)) +
  geom_density(fill = "lightblue", alpha = 0.5) +
  geom_vline(xintercept = 0, linetype = "dashed") +
  labs(
    title = "Posterior distribution of dairy difference (g1 - a)",
    x = "Difference in proportion",
    y = "Density"
  ) +
  theme_minimal()

# Posterior probability that dairy is more prevalent in region g1 than a
prob_g1_greater <- mean(dairy_diff > 0)
prob_g1_greater
## [1] 1

The median difference in dairy (0.3394477) contribution tells us the estimated difference in proportion of dairy for pots in region g1 compared to region a. The credible interval gives us a range of plausible values for this difference. The posterior probability that dairy is more prevalent in region g1 than a (100%) tells us how likely it is that the contribution of dairy is higher in g1 compared to a based on the model results. The visualisation of the posterior distribution of dairy difference helps us see the range of possible values for the difference and how much of the distribution is above or below zero.
